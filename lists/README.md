# Word lists

`nawl.csv` is the New Academic Word List 1.2 (lemmatized for teaching) by
Charles Browne, Brent Culligan, and Joseph Phillips, from
https://www.newgeneralservicelist.com/new-academic-word-list. It is licensed
under Creative Commons Attribution-ShareAlike 4.0
(https://creativecommons.org/licenses/by-sa/4.0/) and included here unchanged
so the monthly update doesn't need to download it.

Coxhead's Academic Word List isn't stored here; `scripts/candidate_words.py`
downloads it into `sources/lists/` when needed.
